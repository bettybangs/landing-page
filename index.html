AC-01 / BACKGROUND

The Short Version

After two decades building and running my own swimwear brand: budgets, vendor contracts, regulatory licensing, the full operational load of a small business. I made a move into cybersecurity governance, risk, and compliance and now hold a B.S. in Cybersecurity and Information Assurance, a working stack of CompTIA and AWS certifications, and hands-on experience mapping NIST and ISO 27001 controls to live cloud environments. I'm also an ISC² candidate, working toward the CGRC and CCSP.

What keeps me interested in GRC is that it's ultimately about evidence. A control either works or it doesn't. A risk is either understood or it isn't. Whether I'm mapping NIST controls, investigating an incident, or building compliance tooling, I'm drawn to the work of turning security requirements into something that can be demonstrated, tested, and trusted.

CM-03 / FEATURED BUILD

Risk Whisperer

AI-Powered GRC Control Assessor

Live & shipped

A tool I designed and built end to end: it takes a plain-language description of a system and generates security control assessments, risk scoring, and control-maturity ratings, with a POA&M tracking module, prompt-injection-filtered input handling, and a serverless backend proxy that keeps the API key off the client entirely. Built because I wanted to understand GRC tooling from the inside, not just as an end user.

Built with React · Claude API · deployed on Vercel

CA-05 / READINESS REPORT

SOC 2 Readiness Assessment

Northstar, Inc.: Mock Client Engagement

Demonstration piece

Manual precursor to Risk Whisperer's automated assessments. The control-mapping judgment this report required is what the tool now does programmatically. Independently built a full SOC 2 Type I readiness deliverable for a fictional 12-person SaaS company facing an enterprise deal contingent on certification: control-by-control gap analysis against all nine SOC 2 Security criteria, a prioritized risk register, and a phased remediation roadmap with assigned control owners and evidence requirements. Drafted three full policies (Access Control, Incident Response, Vendor Management) ready for client adoption.

CA-06 / GAP ASSESSMENT

NIST SP 800-53 Gap Assessment

Northstar, Inc.: Expanded Engagement

Demonstration piece

Follow-on engagement expanding the Northstar SOC 2 work into a full NIST 800-53 Rev 5 Moderate baseline gap assessment, scoped to twelve control families relevant to a cloud-native SaaS company. Includes a scoping memo, family-by-family gap analysis, a risk register, a remediation roadmap, and sample SSP and POA&M artifacts. Every finding was individually verified against the actual SP 800-53 control text, correcting several conflated controls along the way, so each gap reflects what the control actually requires rather than an assumed scope.
